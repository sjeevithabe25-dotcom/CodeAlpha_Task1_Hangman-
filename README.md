# CodeAlpha_Task1_Hangman-
Python Hangman Game - CodeAlpha Internship Task 1
CodeAlpha Hangman Game 🎮

Project Overview

The Hangman Game is a simple text-based word guessing game developed using Python as Task 1 of the CodeAlpha Python Programming Internship.

In this game, the player tries to guess a hidden word by entering one letter at a time. The game selects a random word from a list of five predefined words.

Project Objective

The main objective of this project is to practice Python programming fundamentals and develop logical thinking and problem-solving skills.

Features

- Contains 5 predefined words.
- Randomly selects a secret word.
- Allows the player to guess one letter at a time.
- Displays correctly guessed letters.
- Limits incorrect guesses to a maximum of 6.
- Checks invalid inputs.
- Prevents repeated guesses from counting again.
- Displays winning and losing messages.
- Reveals the secret word when the player loses.

Technologies Used

- Language: Python
- Module: random
- Concepts: Lists, strings, while loop, for loop, if-else statements and user input.

How to Play

1. Start the Hangman Game.
2. The computer randomly selects a word.
3. Enter one letter at a time.
4. Correct guesses reveal letters in the word.
5. Incorrect guesses reduce the remaining chances.
6. Guess the complete word to win.
7. If you make 6 incorrect guesses, the game ends.

How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the command:

python hangman.py

6. Follow the instructions displayed on the screen.
